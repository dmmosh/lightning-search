# lightning-search


web server based off of this playlist:
https://youtu.be/Kc1kwm1WyVM?si=9hbO7wzmrd-RHS95


to install:
```
git clone https://github.com/dmmosh/lightning-search
cd ./lightning-search
cmake -S . -B build
cmake --build build
```

to run:
```
./ls # open localhost:8080 on browser
```
